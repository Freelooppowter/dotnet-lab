# dotnet-lab

.NET 现代写法练习与迁移实验场。

## 这是什么

记录从 .NET Framework 时代写法迁移到 .NET 现代写法的过程，每个示例都可运行、可测试。

## 环境

| 项目 | 版本 / 位置 |
|---|---|
| .NET SDK | 10.0.403 |
| SDK 路径 | `E:\dev\dotnet` |
| 目标框架 | `net10.0` |

## 目录

- `Samples/` 现代 C# 语法示例
- `Tests/` 行为验证测试

## 怎么跑

```bash
dotnet build
dotnet test
```
